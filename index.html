How to preview images in a GitHub folder

Copy any GitHub repo or folder URL, paste it into the box above and hit Show. Or prefix any GitHub link with https://gitpics.pages.dev/# and open it directly.

FAQ

Does GitPics need a login?

No. It works with public repositories and needs no account or install.

Does it work on phones?

Yes. It is built mobile-first with swipe navigation and one-tap download.

Why can't GitHub do this?

GitHub's file browser is built for code, not images. It shows generic file icons for every extension, GitPics adds the visual layer that's missing.

Who built this?

Me, Krishna. I got tired of clicking filenames one by one and wrote the fix. It's one HTML file with no build step, so if you want to add something, you really can.

Can I contribute?

Please do. The entire codebase is index.html. Open it, change something, send a pull request. First PRs are very welcome, and I'll help you get yours merged.
