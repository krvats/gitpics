# Contributing to GitPics

Thanks for being here. This project is one file, so getting started takes about a minute.

## Quick start

1. Fork [krvats/gitpics](https://github.com/krvats/gitpics) and clone your fork.
2. Open `index.html` in your browser. There is no build step.
3. Change something, refresh, see it.
4. Commit, push, open a pull request. Say what you changed and why.

## Ways to help (no code needed too)

- Try it on your phone, other browsers and odd repos, then report what breaks
- Suggest or draw design ideas
- Fix typos and clumsy wording
- Pick something from the to-do list in the README
- Tell someone with a huge image repo

## Ground rules

- Keep it one file with no dependencies unless there is a very good reason.
- Keep the look: chunky borders, hard shadows, hand-made feel.
- Small PRs are easier to review and merge than big ones.
- Be kind. Everyone starts somewhere.

If you're unsure about anything, open an issue and ask. Merged PRs earn the contributor badge in the README.
